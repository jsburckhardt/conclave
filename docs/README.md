# Documentation

This directory contains application-specific documentation for **Conclave** — the council runtime CLI built on the GitHub Copilot SDK. Expected contents as the application evolves:

- **CLI usage** — the `council` commands (`init`, `add-member`, `run`, `continue`).
- **`council.yaml` reference** — council identity, members, orchestrator policy, and artifacts (see [CORE-COMPONENT-0003](../project/architecture/core-components/CORE-COMPONENT-0003-configuration.md)).
- **Runtime architecture** — sessions, transcript/artifact stores, permissions, and observability.
- **Operational runbooks** — running and resuming councils.

For the product brief and roadmap, see [`prd.md`](../prd.md). For architecture decisions, core-components, and per-issue pipeline artifacts, see the [`project/`](../project/) directory.
